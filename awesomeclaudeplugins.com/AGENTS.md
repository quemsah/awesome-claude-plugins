# Agent instructions for awesomeclaudeplugins.com

## Documentation location

- Keep all new project documentation, research, design notes, implementation plans, and other standalone documentation under `awesomeclaudeplugins.com/docs/` (create appropriate subdirectories there).
- Do **not** create documentation files or directories at the repository root, and do **not** recreate a root-level `docs/` directory.
- When relocating or referring to documentation, update links and file paths to use `awesomeclaudeplugins.com/docs/` relative to the repository root.
- The existing root `README.md` remains the repository landing page. Keep project documentation in the workspace documentation directory rather than adding new documentation to the repository root.
